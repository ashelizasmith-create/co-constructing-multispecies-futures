CO-CONSTRUCTING MULTISPECIES FUTURES
INDEXHIBIT QUICK LINKS · v0.1 · 20 October 2026

This compact navigation block separates the public project website from its
GitHub repository and gives visitors direct routes to the tool, printing and citation.
It is ready to paste; it has not been applied to the live Indexhibit exhibit.

ADD QUICK LINKS TO YOUR ALREADY-EDITED PAGE
1. Keep a copy of your current exhibit text.
2. Open Co-Constructing_Multispecies_Futures_Indexhibit_Quick_Links_v0.1.txt as text.
3. Copy the complete block, including the <style> section.
4. Paste immediately after the introduction's closing </p>, before any image block.
5. Preserve your existing text and native card-image gallery. If the image insert is
   already installed, put these quick links before that insert's <style> block.
6. Remove the repeated Interactive Tool, Print the Card Deck and About & cite links
   from the old lower link row. Keep Lead a Session, Workshops & development,
   Examples and Versions there as contextual links.
7. Preview, save and check the page on desktop and a narrow screen.

PAGE ORDER
Introduction -> Quick links -> Image insert -> Context and further links.
Both main destinations appear before the photographs. Links open in the same tab.
The black button opens the public project website. The outlined button opens GitHub.

USE ONE INSTALLATION METHOD
Use the small Quick Links insert with your already-edited exhibit, OR use the
refreshed Co-Constructing_Multispecies_Futures_Indexhibit.html/.txt full-text fragment.
The refreshed full-text fragment already contains these quick links; do not add
the small insert a second time. It does not contain the separate image insert.
For your current page, the small insert preserves your latest text edits.
