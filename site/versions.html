Interactive Tool / First tracked version

v0.1.0

Development20 October 2026

A starting version to use, reflect on, and develop together. It brings the supplied interactive tool into the Co-Constructing Multispecies Futures project, alongside the Card Deck and a guide for embodied worldbuilding.

What this version brings together

  • Start with Spatial and Temporal, add optional layers, and hold a result while drawing again.
  • Edit the adapted prompt bank for your setting. The Card Deck browser separately presents the original artwork and full source-card text.
  • Move between Tell it and Now: try it, with space for writing, voice recording, and embodied rehearsal.
  • Save the current session slip and notes as text or JSON, or print them. Download a voice recording separately.
  • Find the 94-card general selection in Letter and A4 home-print formats, with fold-and-glue and duplex options.

What will a new number mean?

Patch / A fixA repair or refinement within the same experience, such as a clearer label, an accessibility improvement, or a corrected download.

0.2.0 / An additionA new feature, prompt layer, or substantial addition to what the tool can do.

1.0.0 / A stable editionA deliberate milestone when the project's methods, content, credits, and supported behavior are ready for a stable release.

Earlier numbered downloads will remain available when the current online tool changes. The changelog will explain what changed, so you can decide whether to stay with a familiar version or try the next one.

Which version should I record?

For a workshop, publication, or shared activity, record the exact version you used and the date you used it. Save its numbered HTML download alongside your session notes. The current online tool can change, so its address alone does not identify the same experience over time.
