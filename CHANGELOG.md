## 0.1.0 — First tracked development version

**Status at this baseline:** development version 0.1.0 had a reviewed numbered HTML snapshot and verified private preview. Pages was configured for Actions and GitHub–Zenodo integration was enabled, but public Pages deployment and archival publication had not yet occurred. The later website publication is recorded under 0.1.1 above.

### Added

- A project website bringing together the Card Deck, original-card browsing, use guidance, print downloads, and the Interactive Tool.
- A general selection of 94 cards / 188 sides extracted from the original print master, with source page mapping and checksums.
- Four home-print editions: Letter and A4, each in single-sided fold and long-edge duplex layouts; two separate instruction sheets include calibration squares.
- Accessible card text and documentation distinguishing the general selection, the complete multispecies deck, and the related PLF workshop edition.
- Current-session text and JSON export and session-slip printing in the integrated Interactive Tool. Audio remains a separate download.
- A version convention, provenance records, publishing guidance, and draft Zenodo metadata.
- A version-history page and a snapshot command that verifies release metadata and refuses to replace different contents under an existing version number.
- A conventional research-toolkit README, a paper overview, and publication metadata linking the tools to the forthcoming *Performing the What-If* book chapter without publishing its manuscript.
- A searchable workshop and development history with CSV/JSON downloads, distinguishing workshops, planned sessions, presentations, and related embodied practice.
- A clearly labeled Indexhibit preview and matching HTML/TXT paste fragments for the existing asheveryday.com exhibit, preserving its existing gallery image.

### Changed

- Standardized active branding to **Co-Constructing Multispecies Futures — Interactive Tool**, with `site/interactive.html` as the current tool path. Historical names remain in preserved source provenance.
- Framed the method through the supplied manuscript: embodied worldbuilding, speculative scenes, encountering, moving with, becoming-with, and reflection feeding another iteration.
- Acknowledged both *The Thing From The Future* and the *Rehearsing Realities* framework.
- Added the FoodID handout's 2046 sensory-memory, self-authored speculation, and group-story recipe as an optional contextual approach.
- Distinguished the tool's adapted prompt bank from the original physical-card corpus.

### Preserved

- The supplied original HTML, original repository PDFs, original artwork, and historical attribution evidence.
- Existing creator credit names while changing the active project title.
- The repository's existing CC0 1.0 dedication.
